開源範本 · Cloudflare Workers + D1

雲倉預約系統範本

一套完整可用的 LINE 預約系統，單一 Cloudflare Worker 搭配 D1 資料庫，包含客人端 LIFF 預約流程、多服務人員排程、後台管理與一整套安全機制。程式碼開源，你可以部署一份完全屬於自己的版本。

在 GitHub 上查看原始碼 看看預約頁面長怎樣

功能亮點

LINE 整合預約

LIFF 網頁預約表單 + LINE 官方帳號自動回覆，客人不用下載 App、不用註冊帳號。

雙排程模式

手動建立時段，或依服務人員每週班表自動計算可預約時間，兩種模式可以並行使用。

完整後台管理

預約管理、行事曆、顧客標記、服務項目、報表、多帳號權限（管理員／員工）。

帳號安全機制

PBKDF2 密碼雜湊、登入失敗鎖定、Cloudflare Turnstile 機器人驗證、可自訂後台登入路徑、異地登入警示。

預約防濫用

電話格式檢查、黑名單、重複預約提示、可調整的最晚預約／取消／改期時數限制。

LINE 通知稽核

所有推播/回覆訊息都留有紀錄，成功失敗一目了然，方便排查「客人說沒收到通知」。

技術架構

單一 Worker、單一 D1 資料庫，沒有額外的後端伺服器或第三方服務。

Cloudflare Workers

處理所有路由：靜態網站、公開 API、LINE Webhook、後台管理、Cron 排程提醒。

Cloudflare D1

SQLite 相容資料庫，schema 由 migrations 依序建立與演進。

LINE Messaging API + LIFF

經典 LIFF（掛在 LINE Login channel 下），不需要 LINE Mini App 審核即可上線。

部署步驟

全程用 Cloudflare 免費方案即可開始。以下指令在專案根目錄執行。

  1. 安裝依賴、登入 Cloudflare

    npm install
npx wrangler login

  2. 建立你自己的 D1 資料庫

    npx wrangler d1 create cloudcang-booking-template

    指令會印出一個 database_id，把它貼到 wrangler.toml 的 database_id 欄位（原本是 REPLACE_WITH_YOUR_OWN_D1_DATABASE_ID 這個佔位字串）。

  3. 套用資料庫結構

    for f in migrations/*.sql; do
  npx wrangler d1 execute cloudcang-booking-template --remote --file="$f"
done

    依序執行 migrations/ 裡所有的 .sql 檔案。

  4. 部署

    npx wrangler deploy

    完成後會拿到一個 *.workers.dev 網址。

  5. 開啟 /setup 完成初始化

    打開 https://你的網址/setup，會看到一個開箱設定精靈：填站名、建立第一組管理員帳號、（選填）LINE 串接金鑰、建立第一個服務項目、（選填）第一位服務人員。完成後這個頁面會自動關閉，不能重複執行。之後就能從 /admin 用剛設定的帳密登入後台。

  6. （選用）串接 LINE 官方帳號

    到 LINE Developers 建立 Messaging API channel 與掛在同一組 LINE Login channel 下的經典 LIFF，把 Channel Secret／Access Token／LIFF ID 填進後台「第三方串接」頁面，Webhook URL 設為 https://你的網域/api/line/webhook。沒有串接 LINE 也能純用後台手動建立預約。

安全提醒：如果對外公開使用，建議一併設定 Cloudflare Turnstile 機器人驗證，並把後台登入路徑從預設的 /admin 換掉。忘記密碼或想在不經過網頁的情況下重設帳號，可以用 node scripts/create-admin.js 帳號 密碼 產生 SQL 手動執行（/setup 完成後就無法再用來建立新帳號了，但這支工具可以覆蓋既有帳號的密碼）。
這是一套開源範本，程式碼可自由取用、修改、部署到你自己的 Cloudflare 帳號下。完整技術細節請見原始碼與 src/ 內各檔案的註解。
